## 二、模型：Qwen3.8-Flash-Next

| 项目 | 值 |
|---|---|
| 架构 | MoE（混合专家） |
| 总参数 | 125B |
| 每 token 激活 | 约 6B |
| 上下文 | 128K（131072），可扩到 256K |
| 量化规格 | Q2_0 / IQ2_XS / IQ3_XXS / IQ3_S / Coder |
| 多模态 | 支持（`--vision`，走 `strata-vision.exe`） |

### 量化规格怎么选

| 规格 | 磁盘占用 | 质量 | 速度 | 建议 |
|---|---|---|---|---|
| **Q2_0** | 最小 | 最低 | 最快 | 显存紧张时用 |
| **IQ2_XS** | 约 68GB | 可用 | 快 | **本仓库实测用这个** |
| **IQ3_XXS** | 更大 | 较好 | 中等 | 显存宽裕时 |
| **IQ3_S** | 最大 | 最好 | 较慢 | 追求质量 |
| Coder | 中等 | 代码特化 | 快 | 纯代码场景 |

**关于 IQ2_XS 的一个重要更正：** 2-bit 量化常被认为「工具调用不可靠」。
本机实测**推翻了**这个推断——工具调用准确率 **9/9 = 100%**，参数 JSON 零错误。
不需要为了工具调用而降级到 IQ3_S。

## 四、启动参数详解

配置文件位于 `STRATA_HOME\strata-<profile>.json`，由上游 `setup.py` 生成。
以下是各参数的作用、实测取值和调整建议。

### 显存相关（**最重要**）

| 参数 | 本机值 | 说明 | 可调范围 |
|---|---|---|---|
| `--vram-reserve-mib` | **3072** | 给桌面/驱动留多少显存。**默认 700 对驱动桌面的卡严重不足** | 独占卡 700；驱动桌面 **3072** |
| `--max-context` | 131072 | 最大上下文。KV 缓存是显存大户 | 32768 / 65536 / 131072 |
| `--kv` | int8 | KV 缓存精度。int8 比 fp16 省一半显存 | `int8` / `fp16` |
| `--kv-resident` | 32768 | 常驻显存的 KV token 数，其余按需流式读取 | 16384 / 32768 / 65536 |
| `--expert-cache` | auto | 专家缓存大小。auto 会在实际写入后再校验一次并自动缩小 | 保持 `auto` |

> ⚠️ **改 `--vram-reserve-mib` 之前先读** [`05-troubleshooting.md`](05-troubleshooting.md#a-引擎跑到一半没了--请求永远不返回--报-out-of-memory)。
> 这是本项目唯一会导致整套方案彻底不可用的参数。

### 性能相关

| 参数 | 本机值 | 说明 | 可调范围 |
|---|---|---|---|
| `--pool-workers` | 15 | CPU 工作线程数。经验值 ≈ 物理核心数 × 0.6 | 8 / 15 / 24 |
| `--prefill` | auto | 预填充分块大小。`auto` 会自动选（本机是 8192） | `auto` / 2048 / 4096 / 8192 |
| `--spec` | 4 | 投机解码的草稿长度 | 0（关）/ 2 / 4 / 8 |
| `--spec-min-p` | 0.5 | 接受草稿的最低概率阈值 | 0.3–0.7 |

`--pool-workers` 的实测（上游数据，16 核机器）：15 线程 38–42 tok/s，8 线程 36，24 线程（每逻辑核一个）反而降到 27。**不是越多越好。**

### 其它

| 参数 | 说明 |
|---|---|
| `--expert-profile` | 专家路由画像文件，记录哪些专家常被用到 |
| `--mtp` | 多 token 预测运行时目录 |
| `--vision` | 启用图像输入 |
| `--pack` | 打包的专家权重目录 |

## 五、显存账（24GB 卡）

| 项 | 占用 |
|---|---|
| 桌面常驻（浏览器/聊天/Steam/录屏等） | 约 2000 MiB |
| 引擎（权重 + KV + 工作缓冲） | 约 19000 MiB |
| **`--vram-reserve-mib` 预留** | **3072 MiB** |
| 实际空闲 | 约 2750 MiB |

**Ollama 与 Strata 不能同时运行：**

```
ollama  qwen3.8:27b-q4_K_M   23.2 GB
Strata  Qwen3.8-Flash-Next   15.0 GB
                             ───────
                             38.2 GB  >  24 GB
```

dsh 本身不占显存，所以切换引擎时**不需要重启 dsh**，只要在模型选择器里换一项。

## 六、如果显存不够

按性价比排序：

1. **提高 `--vram-reserve-mib`** —— 首选，代价最小
2. **关掉抢显存的桌面程序** —— 实测这台机器上桌面常驻就有约 2GB
3. **`--kv-resident` 32768 → 16384** —— 牺牲长上下文复用速度
4. **`--max-context` 131072 → 65536** —— 直接砍 KV 缓存
5. **`--prefill auto` → 4096** —— 更小的分块借用更少缓存槽
6. **换更小的量化规格** —— Q2_0
