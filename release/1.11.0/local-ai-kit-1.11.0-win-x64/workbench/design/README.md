## codex-switcher/

`Codex 切换器` 的高保真 Web 原型。

| 文件 | 说明 |
|---|---|
| [`codex-switcher/index.html`](codex-switcher/index.html) | 单文件原型，零依赖，双击用浏览器打开即可 |
| [`codex-switcher/DESIGN.md`](codex-switcher/DESIGN.md) | 完整设计规范（布局 / 区块 / 交互 / 视觉令牌 / 响应式） |

**怎么预览**：直接双击 `codex-switcher/index.html`。不需要起服务器，不需要联网。

**这个原型是什么**

把桌面端的 `Codex 切换器`（Python + tkinter 写的面板，源码在
`C:\Users\xukunhang\.codex\switcher\`）按原样还原成 Web 版本，
用于设计评审和后续移植。

**还原度**

- 配色直接取自 `codex_switcher.py` 的 `DARK` / `LIGHT` 两套字典，逐像素同色
- 控件、文案、下拉选项、说明文字全部来自真实源码，没有编造的占位内容
- 布局与参考截图逐项对照过，见 `DESIGN.md` 第六节

**原型比原版多出来的东西**（都在窗口之外，不影响还原度）：

- 窗口外壳（标题栏），为了在浏览器里还原桌面窗口观感
- 右下角演示控件：深色 / 浅色主题切换、窄屏预览（压到 400px）、重置日志

**交互都是可点的**

服务商单选会级联切换模型列表、推理档位、上下文上限的启用状态和说明文字；
切到「端砚 API 密钥」时若网关没跑会自动拉起；
「应用并重启」会禁用全部按钮并逐行播放日志。

## 设计约定的几点说明

**为什么用单文件 HTML**

和工作台的 WebUI 一样，坚持零依赖：不用框架、不用 CDN、不用图标字体。
下拉箭头是纯 CSS 画的，窗口按钮用 Unicode 字符。这样双击就能看，
不会因为加载失败而白屏。

**为什么有两套主题**

原桌面端会跟随 Windows 的深色/浅色设置（`system_dark()` 读注册表）。
Web 原型里给了手动切换，方便一次看全两套令牌。

**为什么表单三列要底对齐**

三个标签（模型 / 推理强度 / 上下文上限）字数不同，顶部对齐会让三个
输入框参差；底对齐保证它们落在同一条水平线上。
