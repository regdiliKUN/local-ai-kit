## 一、整体布局结构与区域划分

### 1.1 骨架

单列纵向流式布局。窗口内所有内容共用同一个左边界（`18px` 内边距），
卡片之间靠 `12px` 间距分隔，**没有左右分栏、没有侧边栏、没有标签页**。

```
┌─ 窗口 (720px) ─────────────────────────────────────────────┐
│  标题栏 36px  [图标] Codex 切换器            — □ ✕          │
├────────────────────────────────────────────────────────────┤
│                                                            │
│   Codex 切换器                          ← 页面标题 h1      │
│   （副标题，默认空）                     ← 预留位           │
│                                                            │
│  ┌─ 卡片 1 ─────────────────────────────────────────────┐  │
│  │ 当前：官方账号                    ← 卡片标题 15px 粗  │  │
│  │ 模型 gpt-6.1-sol · 推理 high      ← 等宽 12.5px 次要  │  │
│  │ 配置 C:\...\config.toml                              │  │
│  └──────────────────────────────────────────────────────┘  │
│                    ↕ 12px                                  │
│  ┌─ 卡片 2 ─────────────────────────────────────────────┐  │
│  │ 服务商                             ← 字段标签 12px    │  │
│  │ ◉ 官方账号  ○ 端砚 API 密钥  ○ DeepSeek 官方         │  │
│  │                                                      │  │
│  │ 模型              推理强度      上下文上限           │  │
│  │ [gpt-6.1-sol ▾]  [high ▾]      [— ▾]                 │  │
│  │                                                      │  │
│  │ 使用 Codex 桌面端已登录的官方账号…  ← 说明文字       │  │
│  └──────────────────────────────────────────────────────┘  │
│                    ↕ 12px                                  │
│  ┌─ 卡片 3（状态条，矮）───────────────────────────────┐  │
│  │ ● 网关状态检查中…        [启动网关][停止网关][重置]  │  │
│  └──────────────────────────────────────────────────────┘  │
│                    ↕ 14px                                  │
│  [ 应用并重启 Codex ]  [只写配置]  [刷新端砚模型目录]       │
│                    ↕ 12px                                  │
│  ┌─ 日志区（等宽，min-height 132px）───────────────────┐  │
│  │ 已读取当前配置。                                     │  │
│  │                                                      │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 1.2 区域划分表

| # | 区域 | 纵向位置 | 高度特征 | 背景 |
|---|---|---|---|---|
| 0 | 标题栏 | 顶部 | 固定 36px | `--titlebar`（比页面底更深） |
| 1 | 页面标题 | 标题栏下 | 自适应 | 透明（露出 `--bg`） |
| 2 | 当前状态卡 | 上 | 自适应（2 行文字） | `--card` + 1px 描边 |
| 3 | 配置卡 | 中 | 自适应（最高） | `--card` + 1px 描边 |
| 4 | 网关状态条 | 中下 | 固定约 52px | `--card` + 1px 描边 |
| 5 | 操作按钮行 | 下 | 自适应 | 透明（露出 `--bg`） |
| 6 | 日志区 | 底部 | `min 132px` / `max 240px`，可滚 | `--card` + 1px 描边 |

### 1.3 层级关系

三层，靠**背景明度**而非阴影区分（桌面端风格，不用卡片投影）：

```
层级 1  页面底      --bg      #1c1d21   ← 最深，衬托卡片
层级 2  卡片 / 控件面 --card    #26282d   ← 比底亮一档
层级 3  输入控件    --entry   #2c2f35   ← 比卡片再亮一档
```

描边统一 `1px solid var(--line)`（`#3a3d43`），圆角：卡片 `6px`、控件 `4px`、窗口 `8px`。

## 二、各主要功能区块及其用途

### 卡片 1 · 当前状态

**用途**：让用户一眼确认「Codex 现在实际在用哪套配置」，避免改错了不知道。

| 元素 | 内容 | 数据来源 |
|---|---|---|
| 卡片标题 | `当前：<服务商名>` | `core.config_summary()['mode_label']` |
| 第 1 行 | `模型 <id> · 推理 <effort>` | 当前 config.toml 的模型与推理强度 |
| 第 2 行 | `配置 <完整路径>` | `~/.codex/config.toml` |

> 这两行用**等宽字体**，因为内容是机器可读的标识符与路径，等宽便于逐字核对。

### 卡片 2 · 配置

**用途**：本面板的核心操作区，选择「用哪家服务商 + 哪个模型 + 多强的推理」。

| 子区 | 控件 | 说明 |
|---|---|---|
| 服务商 | 3 个横向单选 | `官方账号` / `端砚 API 密钥` / `DeepSeek 官方` |
| 模型 | 下拉（可输入） | 列表随服务商变化 |
| 推理强度 | 下拉（只读） | 选项随服务商变化 |
| 上下文上限 | 下拉（只读） | **仅端砚模式可用**，其余模式置灰显示 `—` |
| 说明文字 | 静态段落 | 随服务商切换，解释该模式的连接方式 |

### 卡片 3 · 网关状态条

**用途**：端砚模式依赖本机 `127.0.0.1:18791` 代理，这行告诉你代理活着没有、密钥消耗到什么程度。

| 元素 | 行为 |
|---|---|
| 状态圆点 | 灰 = 未运行，绿 = 运行中（带一圈淡绿光晕） |
| 状态文字 | 运行中：`网关运行中 · 当前第 3 把 · 共 6 把可用 · 已标记 #2`<br>未运行：`网关未运行（端砚模式会自动拉起）` |
| 启动 / 停止 / 重置 | 三个次按钮，右对齐 |

> 这一条**刻意做成矮卡片**而不是普通卡片，视觉上弱于配置区——它是「状态」不是「操作」。

### 操作按钮行

| 按钮 | 样式 | 用途 |
|---|---|---|
| **应用并重启 Codex** | **主色实心 + 加粗 + 加大内边距** | 写配置 + 重启 Codex，日常唯一要点的按钮 |
| 只写配置 | 次按钮 | 只改文件，不重启（Codex 下次自己读） |
| 刷新端砚模型目录 | 次按钮 | 重新拉取端砚的模型列表 |

**视觉权重**：主按钮用 `--accent` 实心 + 白字 + `font-weight:700` + `padding 10px 18px`，
三个次按钮用 `--btn` 面 + 常规字重 + `padding 9px 14px`。**一屏只有这一个实心按钮**。

### 日志区

**用途**：所有操作的反馈出口。每步操作都往这里追加一行，带颜色区分结果。

| 颜色 | 含义 | 前缀 |
|---|---|---|
| `--ok` 绿 | 成功 | `✓` |
| `--err` 红 | 失败 | `✗` |
| `--warn` 橙 | 警告 / 进行中 | 无 |
| `--sub` 灰 | 次要信息（备份路径等） | 缩进两格 |

新行自动滚到底部。内容用 `white-space: pre-wrap` 保留换行与缩进。

## 三、交互组件与交互逻辑

### 3.1 组件清单

| 组件 | 类型 | 数量 | 状态 |
|---|---|---|---|
| 单选组 | radio | 3 | 默认 / 悬停 / 选中 / 键盘焦点 |
| 下拉选择 | select | 3 | 默认 / 悬停 / 聚焦 / 只读 / **禁用** |
| 按钮 | button | 6 | 默认 / 悬停 / 按下 / 禁用 / 键盘焦点 |
| 状态圆点 | 指示器 | 1 | 灰（未运行）/ 绿（运行中） |
| 日志面板 | 滚动容器 | 1 | 自动滚底 |

### 3.2 联动逻辑（本设计的核心）

服务商是**主控开关**，切换它会级联改变另外三个控件：

```
                  切换「服务商」
                        │
      ┌─────────────────┼─────────────────┐
      ▼                 ▼                 ▼
  模型列表          推理强度选项      上下文上限
  换成该服务商的     换成该服务商       是否需要网关？
  模型清单           支持的档位         ├─ 是 → 启用，恢复该模型默认值
      │                                   └─ 否 → 禁用置灰，显示「—」
      │
      ▼
  说明文字 换成该服务商的 note
```

| 服务商 | 模型示例 | 推理档位 | 上下文上限 | 网关 |
|---|---|---|---|---|
| 官方账号 | `gpt-6.1-sol` | low / medium / **high** / xhigh / ultra / max | 禁用 `—` | 不需要 |
| 端砚 API 密钥 | `Atria-Dawn-Preview` | low / **high** / max | **启用** | **需要** |
| DeepSeek 官方 | `deepseek-flash` | low / **high** / max | 禁用 `—` | 不需要 |

**切到端砚时的自动行为**：若网关没在跑，自动尝试拉起，并在日志里打一行橙色提示；
用户手动点过「停止网关」后本次不再自动拉起（`autostart` 标志）。

### 3.3 忙碌态（Busy）

任何耗时操作（应用、重启、启停网关、刷新目录）都会：

1. 6 个按钮**全部禁用**（`opacity .45` + `cursor: not-allowed`）
2. 清空日志区，逐行播放操作结果（每行间隔 220ms，形成节奏感）
3. 完成后恢复按钮，并刷新「当前状态卡」与「网关状态」

重复点击时若仍在忙碌，日志提示「上一个操作还在进行，稍等。」而不是排队。

### 3.4 键盘与无障碍

| 项 | 实现 |
|---|---|
| 单选组 | 原生 `<input type="radio">`，方向键可切换 |
| 下拉 | 原生 `<select>`，`Alt+↓` 展开 |
| 焦点可见 | `:focus-visible` 时 `outline: 2px solid var(--accent)`，偏移 2px |
| 状态播报 | 网关状态与日志带 `role="status"` / `role="log"` + `aria-live="polite"` |
| 动效偏好 | `prefers-reduced-motion: reduce` 时关闭全部过渡 |

## 四、视觉样式规范

### 4.1 配色方案

**色值直接取自 `codex_switcher.py` 的 `DARK` / `LIGHT` 字典**，保证 Web 原型与桌面端同色。

#### 深色（默认）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--bg` | `#1c1d21` | 页面底 |
| `--card` | `#26282d` | 卡片面 |
| `--line` | `#3a3d43` | 描边 / 分隔线 |
| `--fg` | `#eceff3` | 主文字 |
| `--sub` | `#9aa3ae` | 次要文字 / 标签 |
| `--accent` | `#4f8cff` | 主色：主按钮、选中态、焦点环 |
| `--ok` | `#3fbf6f` | 成功 |
| `--warn` | `#e0a33e` | 警告 |
| `--err` | `#f0605d` | 失败 |
| `--btn` | `#33363c` | 次按钮面 |
| `--btn-hover` | `#3f434a` | 次按钮悬停 |
| `--entry` | `#2c2f35` | 输入控件面 |
| `--titlebar` | `#16171a` | 窗口标题栏 |

#### 浅色（跟随系统主题）

| 令牌 | 色值 |
|---|---|
| `--bg` | `#f2f3f5` |
| `--card` | `#ffffff` |
| `--line` | `#dcdfe4` |
| `--fg` | `#1c1e21` |
| `--sub` | `#5f6672` |
| `--accent` | `#2f6feb` |
| `--ok` / `--warn` / `--err` | `#1f9d55` / `#b8770f` / `#c9382f` |
| `--btn` / `--btn-hover` | `#e8eaed` / `#dadee3` |

> 两套主题**只换令牌值，不改任何结构或尺寸**。原型右下角有切换按钮可直接对比。

### 4.2 字体与字号层级

字体栈：

```css
--font-ui:   "Microsoft YaHei UI","Microsoft YaHei","Segoe UI",system-ui,sans-serif;
--font-mono: Consolas,"Cascadia Mono",Menlo,monospace;
```

| 层级 | 字号 | 字重 | 字体 | 用在哪 |
|---|---|---|---|---|
| H1 页面标题 | 22px | 700 | UI | 「Codex 切换器」 |
| H2 卡片标题 | 15px | 700 | UI | 「当前：官方账号」 |
| 正文 / 单选 | 13px | 400 | UI | 选项文字、下拉内容 |
| 主按钮 | 13px | 700 | UI | 「应用并重启 Codex」 |
| 次按钮 | 12.5px | 400 | UI | 「只写配置」等 |
| 标签 | 12px | 400 | UI | 「服务商」「模型」 |
| 说明文字 | 12px | 400 | UI | 卡片底部的 note |
| 状态文字 | 12.5px | 400 | UI | 网关状态 |
| 等宽 · 详情 | 12.5px | 400 | **Mono** | 模型 id、配置路径 |
| 等宽 · 控件 | 13px | 400 | **Mono** | 模型下拉、推理下拉 |
| 等宽 · 日志 | 12.5px | 400 | **Mono** | 日志区 |

**行高**：标题 1.25–1.3，正文 1.7，日志 1.75。

**用等宽的三个理由**：① 模型 id 是标识符，等宽便于比对；② 路径要对齐；③ 日志需要垂直对齐。

### 4.3 间距与对齐规则

**4px 基准的间距阶梯**：

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--sp-1` | 4px | 卡片标题与详情行之间 |
| `--sp-2` | 6px | 标签与控件之间、按钮之间 |
| `--sp-3` | 8px | 操作按钮行间距 |
| `--sp-4` | 12px | **卡片之间**、单选行与表单之间 |
| `--sp-5` | 14px | **卡片内边距**、表单三列之间 |
| `--sp-6` | 18px | **窗口左右内边距** |
| `--sp-7` | 24px | 窗口底部内边距 |

**对齐规则**：

1. **左对齐为唯一基准**——所有卡片、标题、按钮行共用同一条左边线（窗口内边距 18px）。
2. **卡片内元素再缩进 14px**，与卡片描边形成两档视觉缩进。
3. 表单三列用 `flex` + `gap 14px`，**底对齐**（`align-items: flex-end`）——
   因为标签文字长度不同，顶部对齐会让控件参差，底对齐保证三个输入框在同一条水平线上。
4. 按钮组**右对齐**（网关行）或**左对齐**（操作行），取决于该行有没有占位的状态文字。
5. 日志区与卡片同宽、同圆角，形成「这也是一个卡片」的视觉归类。

### 4.4 图标风格

**本界面刻意不用图标字体、不用 SVG 图标库**，只用三种元素：

| 元素 | 实现 | 用在哪 |
|---|---|---|
| 品牌方块 | CSS 渐变方块 `linear-gradient(135deg,#6f7cff,#4f8cff)` + 内嵌白色描边 | 标题栏左侧 |
| 状态圆点 | 9px CSS 圆形，`--ok` 时加 3px 淡绿光晕 | 网关状态条 |
| 下拉箭头 | **纯 CSS** 两个 5px 方块旋转 45°，颜色 `--sub` | 三个 select |

**为什么这么做**：

- 桌面工具面板的图标应当**克制**——参考图里除了品牌方块和状态圆点，没有任何装饰性图标。
- 用 CSS 画箭头而不是引入图标字体，保证**零依赖、无字体加载失败风险**。
- 窗口控制按钮（— □ ✕）用 Unicode 字符 `&#8211; &#9633; &#10005;`，不引图标字体。

**视觉语言**：圆角矩形 + 细描边 + 单色，不使用投影、不使用渐变（品牌方块除外）、不使用拟物。

## 五、响应式适配

参考图是一个固定尺寸的桌面窗口。原型在保持桌面观感的前提下，
让它在窄屏下不破版：

| 断点 | 行为 |
|---|---|
| **≥ 640px** | 完整还原参考图：表单三列并排，网关按钮与状态文字同行 |
| **< 640px** | 表单三列 → **纵向堆叠**；网关行的状态文字与按钮**各占一整行**；按钮 `flex:1 1 auto` 拉满宽度；内边距收到 14px |
| **< 420px** | 页面标题降到 17px；单选组间距收紧；标题栏按钮 44px → 36px |
| **任意尺寸** | 窗口宽度 `min(720px, 100%)`，永不超出视口；日志区高度上限 240px 后内部滚动 |

另外处理了 `prefers-reduced-motion: reduce`：关闭全部过渡动画。

> 原型右下角的「窄屏（400px）」按钮可以把窗口强制压到 400px，直接看断点效果。
