本地 AI 使用说明

把大模型跑在你自己的显卡上，不联网、不花钱、不限次数。

👉 你要做的只有一件事

双击这个文件

① 双击这里开始安装.cmd

就在这个文件夹里，名字最长的那个。

双击后会打开一个图形化安装向导。每一步该做什么，页面上都写着，跟着点就行，

全程不需要输入任何命令。

就这一步。 下面的内容都是解释和备用信息，不看也能装好。

双击之后会发生什么

0. 先弹出一个黑色窗口

那是安装程序本体。它会说「接下来会自动打开浏览器」，然后浏览器就会弹出来。

安装期间别关它。 关掉它 = 中断安装。装完再关。

1. 自动检测你的电脑

左边是步骤，右边是内容。第一步会自动识别你的显卡型号和显存、磁盘空间、

已经装了哪些组件，结果显示成一张张卡片。

页面顶部还会告诉你：接下来只需要三步（选模型 → 选存放位置 → 自动安装）。

如果刚装了显卡驱动或 Ollama，点一下页面下方的「重新检测」就行，不用重开向导。

2. 选择要部署的模型

页面顶部有一条蓝色的「怎么做」提示，写着这一屏要干的两件事。

向导会读你的显存，只列出跑得动的模型，最适合的那个标着「推荐」。

每张卡片都写了下载体积、需要多少显存，还按 25MB/s 估算了大概要下多久。

直接点一张选中就行。

如果本机已经下过某个模型，卡片上会标「本机已有」，并告诉你它在哪个目录 ——
直接复用，不用重新下载。

下面还能调上下文长度（4K / 8K / 16K / 32K / 64K），会实时显示估算的显存占用，

并标注「够用 / 偏紧 / 可能超出显存」。拿不准就用默认值。

3. 选择模型存放在哪个盘

列出你所有分区，按空闲空间排序。点一下选中，然后点「开始安装」。

选好之后，页面会告诉你目标盘还剩多少、这次需要多少。不够的话会直接拦住，

不让你带着一个必然失败的任务往下走。

建议避开叠瓦盘（SMR）—— 这种盘持续写入会掉速、寿命也差。
拿不准就选 SSD，或者选那块较新的机械硬盘。
下载慢或连不上模型仓库的话，这一屏最下面可以展开「设置网络代理」。

4. 等待安装（这一步你什么都不用做）

页面顶部会有一条提醒：请保持这个页面开着，也不要关掉那个黑色窗口。

界面上有两层进度：

  • 顶部整体进度 —— 「第 3 / 6 步 · 下载模型」，一眼知道还剩多少
  • 当前步骤的详细进度 —— 下载模型时显示 已下载 / 总大小、实时速度、

预计剩余时间，以及分片进度（例如 分片 3 / 5）

每一步后面还会显示已经用了多久，长时间没动静时也能确认程序还在跑。

下载模型这一步最慢（十几 GB，取决于网速），其余步骤很快。

下载完之后还会有一个「校验模型」步骤：向导会真的把模型加载一次，

确认显存装得下、模型能用 —— 装不下会当场告诉你，而不是等你打开工作台才发现。

中途关掉了也没关系：重新双击那个文件会接着装，已经下载好的部分不会重下。

5. 完成

装好后页面会直接告诉你以后怎么用（就两步），并给你两个按钮：

「立即启动工作台」和「打开安装目录」。桌面上也会出现两个图标。

装好之后怎么用

桌面图标作用
启动本地AI双击它，自动启动服务并打开浏览器工作台
停止本地AI双击它，停止服务、把显存还给你
本地AI控制台加装 / 删除模型、开关开机自启、开关局域网共享

日常使用就两条

  1. 想用 AI → 双击「启动本地AI」，浏览器会自动打开工作台
  2. 不想用了 / 要玩游戏 → 双击「停止本地AI」腾出显存

启动后会弹出一个黑色窗口，保持它开着，它就是服务控制台。
关掉黑窗口等于停止服务。
模型运行时会占约 16GB 显存。玩大型游戏、跑渲染前建议先「停止本地AI」。

关机

随时可以关机，没有任何风险。 不会丢东西，也不会中断任何任务。

重启后双击「启动本地AI」即可。

本地AI控制台（新）

双击桌面上的「本地AI控制台」，浏览器会打开一个小网页，分两页：

模型管理

  • 看：已经装了哪些模型、各占多少磁盘、什么量化
  • 删：点「删除」→ 原地变成「确认删除？」→ 再点一下才真删（不会误删）
  • 装：输入模型名（比如 qwen3:8b）点「下载」，带实时进度、速度、剩余时间
  • 下面还有一排常用模型的快捷按钮，点一下就填进输入框

服务设置

开关说明
开机自动启动工作台打开后每次开机自动启动服务并加载模型（会占显存）。想自己控制就别开。
局域网共享把 Ollama 的接口开放给同一个 WiFi 下的手机 / 平板 / 其它电脑。默认关闭，打开前必须先在警告里打勾确认。

下面还有「启动工作台」「停止服务并释放显存」「打开安装目录」「打开模型目录」，以及一个卸载入口。

局域网共享会把 Ollama 暴露到 0.0.0.0:11434。
在公共 WiFi、宿舍网、公司网里，同网段的任何人都能用你的显卡跑模型。
只在你信任的家庭网络里打开，用完关掉。

想换模型 / 加装模型

两种方式都行：

  1. 控制台（推荐）—— 双击「本地AI控制台」→ 模型管理 → 输入模型名 → 下载
  2. 重跑安装向导 —— 双击部署包里的「① 双击这里开始安装.cmd」，在选模型那一步选别的

删除模型：控制台里点「删除」，会立刻释放磁盘空间，不影响其它模型。

需要提前准备什么

其实什么都不用准备 —— 缺什么，安装程序会自己检测并处理。

软件没装会怎样
Node.js双击后自动下载并安装（约 30 MB），装完自动继续
Ollama安装向导会弹窗问你，点「自动安装 Ollama」就帮你装好，装完自动接着往下装

两者都会弹出一个 Windows 授权窗口，点「是」即可。

如果向导提示需要管理员权限，弹窗里的按钮是「自动以管理员身份继续」——

点一下它就会自己用管理员身份重开，不用你去找文件右键。

如果网络连不上官网，程序会提示你手动下载，并自动帮你打开下载页面。

安装失败 / 卡住了怎么办

新版不会只甩一句报错。 一旦某一步失败，页面会直接展开一块红色的排查面板，

里面写清楚三件事：

  1. 停在了哪一步（比如「停在了：下载模型」）
  2. 原因是什么（把原始报错也显示出来）
  3. 你可以这样做 —— 按顺序列出 1、2、3 条具体操作

面板上还有四个按钮：

按钮作用
重试安装用同样的设置再跑一遍。已装好的步骤会自动跳过，模型支持续传
重新检测重新扫一遍硬件和组件（比如你刚装完 Ollama）
复制诊断信息把环境 + 报错 + 日志一次性复制到剪贴板，直接粘贴发给帮你的人
打开日志打开安装日志文件 %TEMP%\localai-setup.log

安装过程全程会写一份日志到 %TEMP%\localai-setup.log，
在文件资源管理器地址栏输入 %TEMP% 就能找到。

双击后出现英文报错怎么办

如果看到类似这样的英文：

'node' is not recognized as an internal or external command

说明电脑上没装 Node.js。

  • 新版已经处理了这个问题 —— 双击后会显示中文提示，并自动帮你装好 Node.js。
  • 如果你用的是旧版（2026-10-09 之前下载的），请重新下载最新版部署包，

或手动到 https://nodejs.org 下载 LTS 版本装好，再双击本文件。

它是怎么工作的

理解这三层，用起来就不会迷糊：

层是什么有没有界面
Ollama推理引擎，把模型跑在显卡上没有界面，纯后台服务
DeepSeek Harness驾驶舱，让你跟模型对话、派活有，是浏览器里的网页
启动器一键点火一个黑窗口

所以你要"打开"的从来不是某个 AI 软件，而是让后台服务跑起来，然后开浏览器。

桌面那两个快捷方式把这件事合成了一步。

装了 DeepSeek Harness 之后，模型就不只是"会聊天的 API"了 ——

它能读文件、写代码、执行命令、连续完成多步任务。

常见问题

Q：双击后弹出一句英文报错，一闪而过？

那是缺 Node.js（'node' is not recognized...）。新版会自动帮你装 ——

双击后按回车，在授权窗口点「是」即可。

如果还是不行，手动到 https://nodejs.org 装 LTS 版本再重试。

Q：提示"没有检测到 Ollama"？

在向导弹出的窗口里点「自动安装 Ollama」，它会自动下载安装，

装完会自动接着往下装，不用你重新走一遍向导。

也可以自己到 https://ollama.com/download 装好，然后点「重新检测」。

Q：提示需要管理员权限？

点弹窗里的「自动以管理员身份继续」。会弹出一个 Windows 授权窗口，点「是」，

向导会用管理员身份重新打开。不需要你自己去找文件右键运行。

Q：提示「这块盘空间不够」？

向导会按模型体积的 1.3 倍算需要多少空间，不够就不让你点「开始安装」。

换一块空间更大的盘，或者回上一步选个小一点的模型即可。

Q：提示「显卡驱动太旧」？

到 https://www.nvidia.cn/geforce/drivers/ 下载安装最新驱动，重启后回到向导点「重新检测」。

驱动太旧时 Ollama 会偷偷退回 CPU 跑，慢到没法用，所以提前拦住。

Q：下载模型很慢 / 一直连不上？

如果你平时上网需要走代理（Clash、v2ray 之类），在向导的「存放位置」那一步最下面

展开「设置网络代理」，把 HTTP 代理地址（例如 http://127.0.0.1:7890）填进去，下载就会走它。

另外：如果你本机已经有下好的模型，向导会自动发现并直接复用，不用重新下载（选模型时卡片上会标「本机已有」）。

Q：怎么卸载？

打开「本地AI控制台」→ 服务设置 → 最下面点「卸载本地 AI」，

或者到安装目录里双击 卸载.cmd。

卸载程序会先把「要删什么、不删什么」列清楚，再逐条问你确认 ——

模型文件（十几 GB）会单独问一次，只有路径确实是 ...\ollama\models 结构时才允许自动删。

Q：提示「模型加载失败（多半是显存不够）」？

向导在下载完模型后会真的试加载一次，装不下会当场报出来，不会等你打开工作台才发现。

解决办法：回上一步换个小一点的模型，或者把上下文长度调小（选模型那一步可以调）。

Q：下载中断了怎么办？

重新双击「① 双击这里开始安装.cmd」，会接着下，不用重头来。

如果向导还开着，直接点红色面板上的「重试安装」更快。

Q：下载模型时进度条走得慢 / 看起来不动？

界面上显示的速度就是当前真实网速。判断是不是卡住，看两点：

  • 「已下载」的 GB 数还在涨 → 没卡，只是网慢
  • 「已用时」在跳但 GB 数长时间不变 → 大概率是网络断了

断了也不用重来，点「重试安装」或重新双击安装文件都会从断点接着下。

Q：为什么下载模型时还有好几个「分片」？

大模型是拆成多个分片（layer）存放的，Ollama 会同时下几个。

界面显示的是所有分片加起来的总进度，所以不用担心某个分片先到 100%。

Q：浏览器打开后要求登录？

用控制台窗口里打印的那条带 ?token= 的完整地址。

Q：回复很慢？

  • 第一次提问慢是正常的（模型要加载进显存，约 1 分钟）
  • 之后应该每秒几十个字
  • 如果一直很慢，可能是显存不够，选个小一点的模型

Q：显存不够 / 加载失败？

重新运行安装向导，在选模型那一步选个更小的（向导只列跑得动的）。

也可以打开安装目录的 配置.json，把 contextWindow 改小（比如 16384），重启。

Q：聊得久了，AI 突然说「已达输出 token 上限」，点继续也没用？

v1.2.0 已经修好了这个坑：DeepSeek Harness 的自动压缩插件默认预留 65536 token，

而本地模型的窗口没这么大，导致压缩被静默禁用，会话涨满后就再也输出不出来。

新版安装时会自动写入正确的压缩参数，长对话会被自动摘要压缩，不会卡死。

Q：想换一个模型？

重新双击「① 双击这里开始安装.cmd」，在选模型那一步选别的即可。

Q：想换模型存放的盘？

重新运行安装向导，在「存放位置」那一步点另一块盘，或者在下面的输入框里填完整路径（比如 E:\AI\ollama\models）。

注意这会在新位置重新下载一份模型；旧的可以手动删掉释放空间。

Q：我自己改过 DeepSeek Harness 的配置（加过云端模型），重装会不会被覆盖？

不会。 新版安装器只更新它自己那几行（本地 provider、压缩参数），

你在同一个配置文件里手写的其它 provider、插件设置原样保留；

改动前还会在同目录留一份带时间戳的备份（最多保留 3 份）。

Q：桌面图标显示成旧的 / 白的？

在桌面空白处按 F5 刷新。

Q：桌面图标没生成出来？

到安装目录里双击 重建桌面图标.cmd 补回来。

Q：可以装到别的电脑吗？

可以。把这个文件夹整个复制过去，在新电脑上双击「① 双击这里开始安装.cmd」即可。

（模型文件在另一台机器上会重新下载）

Q：用的是 AMD 显卡？

向导会识别 AMD 显卡的显存并推荐模型。但 Ollama 只支持部分 AMD 型号加速，

不支持的会退回 CPU 运行，速度很慢。

Q：启动时提示「运行中的 Ollama 用的不是配置的模型目录」？

正常现象。开机自启的 Ollama 可能用的是别的目录，启动器会自动用正确的目录重启它。

Q：喜欢黑窗口 / 要写脚本自动化？

双击 备用-命令行安装.cmd，功能一样，但没有图形界面。

这个文件夹里都有什么

本地AI部署包\
├── ① 双击这里开始安装.cmd   ← 你只需要双击这个（名字最长的那个）
├── 使用说明.html            ← 本文档的网页版，双击用浏览器打开更好读
├── 使用说明（纯文本版）.md  ← 就是你现在看的这份
├── 备用-命令行安装.cmd      ← 高级用法，一般不用管
├── ui\                      ← 安装向导的界面文件
├── icons\                   ← 桌面快捷方式的图标
└── scripts\                 ← 安装脚本

除了第一个，其他都不用管。

安装完成后，程序装在哪

内容位置大小
程序本体C:\Users\你\AppData\Local\Programs\LocalAI约 520 MB
模型文件你在向导里选的盘，如 I:\ollama\models约 17 GB
安装日志%TEMP%\localai-setup.log很小

安装目录里还有：

  • 配置.json — 模型、模型目录、上下文长度，可以直接改
  • 控制台.cmd — 打开本地AI控制台（和桌面图标一样）
  • 卸载.cmd — 一键卸载
  • 重建桌面图标.cmd — 快捷方式被误删时双击它恢复

安装向导还会写入几个用户环境变量（OLLAMA_MODELS、OLLAMA_CONTEXT_LENGTH、

OLLAMA_FLASH_ATTENTION、OLLAMA_KV_CACHE_TYPE、OLLAMA_KEEP_ALIVE），

让开机自启的 Ollama 也用同一个模型目录和参数。

它还会更新 DeepSeek Harness 的配置（C:\Users\你\.dsh\profiles\），

但只动它自己那几行，不会碰你手写的其它内容。

卸载

推荐：一键卸载。 两个入口，效果一样：

  • 打开「本地AI控制台」→ 服务设置 → 最下面点「卸载本地 AI」
  • 或者到安装目录里双击 卸载.cmd

它会按顺序做完这些事，每一步都先问你：

  1. 停止服务（工作台 + Ollama）
  2. 删除桌面上的三个快捷方式
  3. 单独问一次要不要连模型文件一起删（十几 GB）——

只有路径确实是 ...\ollama\models 结构时才允许自动删，否则只提示你手动处理

  1. 清理安装时写入的 OLLAMA_* 用户环境变量
  2. 单独问一次要不要顺手卸载 Ollama 和 Node.js（一般不需要，它们可能还有别的用途）
  3. 删除安装目录本身

手动卸载也行：停服务 → 删桌面图标 → 删安装目录 → 删模型目录 →
在开始菜单搜「编辑账户的环境变量」删掉 OLLAMA_ 开头的几项。

安全提醒

  • 不要把 Ollama（11434 端口）或工作台（3080 端口）映射到公网
  • 让 AI 首次操作时，先用一个可以随便丢的文件夹试，确认没问题再指向重要项目
  • 本地模型不会把你的内容发到网上 —— 这正是本地部署的意义
  • 安装向导只接受来自它自己页面的操作，其他网页无法借它安装程序；

下载的 Node.js 和 Ollama 安装包会先校验 SHA256 / 数字签名，对不上就不安装

更新日志

v1.3.0

这一版把「装完之后的日常」补齐了：模型能自己加删、设置能自己开关、想删能干净卸掉。

新增：本地AI控制台（桌面第三个图标）

  • 模型管理 —— 列出已装模型（体积 / 量化 / 日期），一键删除（原地二次确认，不会误删），

一键加装（输入模型名 + 常用模型快捷按钮，带实时进度 / 速度 / 剩余时间）

  • 服务设置 —— 开机自启开关、局域网共享开关、启动工作台 / 停止服务、

打开安装目录 / 模型目录

  • 局域网共享默认关闭，打开前必须在警告里打勾确认（会明确告诉你会暴露什么）

新增：一键卸载（控制台里，或安装目录的 卸载.cmd）

  • 先把「要删什么、不删什么」逐条列清楚，再逐条确认
  • 模型文件单独问一次，而且只有路径确实是 ...\ollama\models 结构时才允许自动删
  • 删除安装目录用延迟删除，绕开「自己正跑在里面删不掉」的问题

新增：下载加速

  • 本机模型扫描与复用 —— 自动扫描各盘的 ollama\models，已经下好的模型在选模型时标

「本机已有」，直接复用，省掉一次十几 GB 的下载

  • 可选 HTTP 代理 —— 下载慢或连不上模型仓库时，可以填代理地址（走命令行下载，因为

Node 自带的 fetch 默认不认系统代理，而 Ollama 认 HTTPS_PROXY）

新增：两项预检，把问题拦在下载之前

  • 磁盘空间预检 —— 按模型体积的 1.3 倍校验目标盘剩余空间，不够就在界面上直接警告

并禁用「开始安装」，服务端也再拦一道

  • 显卡驱动版本预检 —— 解析 nvidia-smi 的驱动版本，低于保守下限报错、低于建议值提示升级，

并附驱动下载地址（驱动太旧时 Ollama 会静默退回 CPU，慢到没法用）

新增：上下文长度可调 + 模型完整性校验

  • 选模型那一步可以直接切 4K / 8K / 16K / 32K / 64K，实时显示估算显存占用，

并标注「够用 / 偏紧 / 可能超出显存」

  • 新增「校验模型」安装步骤：下载完先用 /api/show 确认注册成功，

再真的试加载一次（1 token）—— 显存装不下会当场报出来，

而不是等你打开工作台提问才发现「本地运行失败」

v1.2.0

这一版重点是把「每一步该做什么」讲清楚，以及把出错后的自救路径补上。

交互引导

  • 每一步都加了「怎么做」指令条 —— 选模型、选盘这两屏顶部直接写明

「① 点一下卡片 ② 点右下角继续」，不用猜

  • 检测页新增「接下来只需要三步」预告 —— 一进来就知道全程要干什么、还差多少
  • 新增「重新检测」按钮 —— 刚装了驱动或 Ollama 不用重开向导
  • 模型卡片显示预计下载时间 —— 按 25MB/s 估算，心里有数
  • 安装页新增「请保持这个页面开着」提醒条，并说明中断了也能续装
  • 完成页改成「以后怎么用（就两步）」图文，并新增

「立即启动工作台」「打开安装目录」两个按钮，装完可以直接用

出错时的自救路径

  • 失败不再只甩一句报错：页面展开排查面板，写清「停在哪一步 / 原因 / 你可以这样做」，

并按步骤给出 1、2、3 条具体操作

  • 新增「重试安装」 —— 已装好的步骤自动跳过，模型支持续传
  • 新增「复制诊断信息」 —— 环境 + 报错 + 日志一键复制，方便发给别人排查
  • 新增「打开日志」 —— 全程写日志到 %TEMP%\localai-setup.log
  • 缺 Ollama 不再算「失败」：改成「需要你完成一步操作」，

点「自动安装 Ollama」装完后自动接着往下装，不用重新走一遍向导

  • 权限不足可以自动提权：弹窗按钮改成「自动以管理员身份继续」，

点一下自动以管理员身份重启向导，不用用户自己去右键

  • 控制台启动横幅重写 —— 明确写出「会自动打开浏览器」「保持窗口开着」

「浏览器没打开就复制这个地址」，端口全被占用时给出排查命令

修掉的问题

  • 修掉一个会覆盖用户配置的严重 bug —— 之前只要配置文件是以

「由本地 AI 安装向导生成」开头，重装时就会整份覆盖，

把用户自己加的云端 provider、插件设置全部抹掉。

现在改成定点合并：只替换本地 provider 和压缩参数，其余原样保留，

改动前还会备份（最多保留 3 份）

  • 修掉「长对话被截断」 —— DeepSeek Harness 的自动压缩插件默认预留 65536 token，

和本地模型窗口一样大，导致压力预算为负、压缩被静默禁用；

会话涨满后报「已达输出 token 上限」，点「继续」也救不回来。

新版安装时自动写入正确的压缩参数（headroomTokens: 8192 等）

  • 上下文长度上限从 32768 提到 65536 —— 配合 KV cache 量化，

24GB 显存可以全量驻留 64K 上下文（实测 RTX 4090 占 22.7G/24.5G）

  • 安装向导会把每个模型对应的上下文长度算好再下发，命令行安装和图形向导不再各算一套

  • 每一步显示已用时 —— 装依赖、启动服务这类没有百分比的步骤，

改成滚动进度条 + 计时，不再看起来像卡死。

  • 下载 Ollama 安装包时也有进度了 —— 之前这一步界面上完全没有提示。
  • 安装 DeepSeek Harness 改为流式输出 —— 界面不再一动不动。
