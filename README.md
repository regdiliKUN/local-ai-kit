# 本地 AI 一站式部署

一个**图形化安装向导**，自动识别你的电脑配置、按显存推荐合适的模型，一键把大模型跑在本地显卡上。

不联网、不花钱、不限次数。

装完之后还有一个**本地控制台**：看得见显存占用、能直接跟模型对话、能量出快慢、能一键修问题。

已有 **Strata 工作台** 的电脑也可以接入本控制台，统一查看和启停引擎、WebUI、dsh。
参见 [接入已有 Strata 部署](docs/strata-integration.md)。

---

## 它解决什么问题

想在本地跑大模型，通常要面对：装 Node.js、装 Ollama、拉模型、配环境变量、配 Agent 框架、
处理各种路径和权限问题……任何一步出错都会卡住，而且报错信息对非技术用户毫无意义。

这个工具把这些全部包进一个**双击即用的安装向导**：

- **自动识别硬件** —— 显卡型号、显存大小、磁盘空间、已安装组件，打开就知道
- **按显存推荐模型** —— 只列出你跑得动的，最适合的标「推荐」
- **自动处理依赖** —— 缺 Node.js 自动装，缺 Ollama 自动装，权限不足弹窗申请
- **装完就能用** —— 桌面自动生成两个快捷方式：启动 / 停止

## 快速开始

### 方式一：下载 ZIP（推荐给普通用户）

1. 点右上角绿色的 **Code** 按钮 → **Download ZIP**
2. 解压到任意位置（路径建议用英文）
3. 双击 **`① 双击这里开始安装.cmd`**
4. 跟着向导点「继续」

就这四步。缺什么依赖，安装程序会自己处理。

> 嫌一步步选麻烦？检测页有个「**按推荐装**」按钮，用推荐值一步到位。
> 目标机器没网？控制台「服务设置」里能一键生成**离线安装包**，拷过去解压就能装。

### 方式二：克隆仓库

```bash
git clone https://github.com/regdiliKUN/local-ai-kit.git
```

然后双击 `① 双击这里开始安装.cmd`。

### 方式三：从 Releases 下载

到 [Releases](https://github.com/regdiliKUN/local-ai-kit/releases) 页面下载打包好的 zip。

## 硬件要求

| 项目 | 最低 | 推荐 |
|---|---|---|
| 显卡 | NVIDIA 16GB 显存 | NVIDIA 24GB 显存（如 RTX 4090） |
| 内存 | 32 GB | 64 GB |
| 磁盘 | 30 GB 空闲 | 50 GB 以上空闲 |

没有独立显卡也能跑，但只能用小模型，速度很慢。
AMD 显卡能识别显存并推荐模型，但 Ollama 只支持部分型号加速；Intel 集显按无独显处理。

## 工作原理

安装完成后，你的电脑上会有三层：

| 层 | 是什么 | 有没有界面 |
|---|---|---|
| **Ollama** | 推理引擎，把模型跑在显卡上 | 没有界面，纯后台服务 |
| **DeepSeek Harness** | 驾驶舱，让你跟模型对话、派活 | 有，是浏览器里的网页 |
| **启动器** | 一键点火 | 一个黑窗口 |

装了 DeepSeek Harness 之后，模型不只是「会聊天的 API」——
它能**读文件、写代码、执行命令、连续完成多步任务**。

## 装完之后能做什么

桌面会有三个图标：

| 图标 | 作用 |
|---|---|
| **启动本地AI** | 启动服务并打开浏览器工作台 |
| **停止本地AI** | 停止服务、释放显存 |
| **本地AI控制台** | 加装 / 删除模型、开机自启、局域网共享、启动停止服务、卸载 |

**本地AI控制台**是个本地网页（和安装向导同一套零依赖实现）。v1.8.0 起它有十二个页面，**界面支持中文 / English 切换**：

| 页面 | 干什么 |
|---|---|
| **系统概览** | 显存 / CPU / 内存 / 磁盘实时占用 + 趋势线；显卡详情；**显存分账**；驻留模型；**用量统计**；**磁盘健康**；**快速操作条** |
| **模型管理** | 已装模型一览（体积 / 量化 / 能力标签）、搜索排序、删除、**批量删除**、**起别名**、**下载队列**、**空间分析**、**搜官方模型库** |
| **试用** | 直接在控制台里跟模型对话，**对话自动保存**、**上下文环形图**、**重新生成（带分支）**、导出 Markdown |
| **模型对比** | 同一个问题同时问最多 4 个模型，并排看答案与速度；**适配度雷达** |
| **性能基准** | 分开测「生成速度」和「读长提示词速度」，**与历史最佳对比** |
| **上下文与模型** | 改模型 / 窗口 / 压缩参数，实时算压力预算，**窗口分配瀑布图** |
| **模型体检** | 21 题质量基线 + 长上下文漂移 + 采样稳定性，**通过率图表**、**成绩趋势**、**日历热力图**、**模型实测排行**、导出 CSV / Markdown |
| **修复中心** | 十项体检 + 一键修复（建目录、起 Ollama、重打补丁、换掉失效模型、清坏自启项） |
| **诊断与维护** | **网络连通性**、**清理下载残留**、**下载诊断报告** |
| **服务** | 引擎 / WebUI / dsh / Ollama 的状态与启停，一页看全 |
| **服务设置** | 开机自启、局域网共享、配置备份、日志、**自愈开关**、**配置检查点**、**快捷键自定义**、**界面缩放**、**离线安装包**、**界面语言** |
| **帮助** | 12 张卡片，每张说清一个页面能干什么，点一下就跳过去 |

按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 打开**命令面板**（也能搜已装模型），输入关键字直接跳到任何页面或动作。

> **两种部署共用同一套界面**：以前 Strata 模式会把控制台「接管」掉，
> 模型管理、测速、体检全被挡掉；现在 Strata 走自己的引擎，
> Ollama 那部分功能管的是 Ollama 装着的模型，两边都能用。

> **Strata 部署也用同一套界面**：以前 Strata 模式会把控制台「接管」掉，只剩三个服务的开关；
> 现在模型管理、测速、体检这些在 Strata 部署下同样可用 —— Strata 走自己的引擎，
> Ollama 那部分功能管的是 Ollama 装着的模型。

## 觉得模型「变笨」？先量一下

装完之后如果感觉回答变短、长对话开始跑偏、或者同一个问题有时对有时错，
**先别急着换显卡**——用体检工具量一下，再决定改什么。

```bat
node healthcheck\quick.mjs
```

它会跑 21 道质量题 + 长上下文漂移 + 采样稳定性，输出一份报告到
`healthcheck\check_out\<时间戳>\run.json`。全程约 40 秒，**只用 Node**，不需要装 Python。

| 你会看到 | 说明 |
|---|---|
| 基线通过率 <90% | 能力确实掉了 —— 换更高的量化档 |
| 某档开始出现「首分歧」 | 数值漂移 —— 把上下文控制在那一档以内 |
| 延迟在某个长度陡增 | **是慢，不是笨** —— 别当成能力问题 |

三种「变笨」的成因和修法完全不同，详见 [healthcheck/IMPACT.md](healthcheck/IMPACT.md)。
其中最常被误判的一种（上下文预算配错）**不需要换硬件**，本仓库已经修了压缩余量的推导方式。

> 装了 Python 3.10+ 的话，`healthcheck/run_all.py` 提供更完整的版本
> （阶梯曲线 SVG、拐点检测、多 seed 稳定性、21 题明细）。
> 两者的判据一致，日常用 `quick.mjs` 就够。

从下载到使用的完整链路审计、以及"变笨了该在哪一步介入"，见
[healthcheck/USER-JOURNEY.md](healthcheck/USER-JOURNEY.md)。

## 常见问题

**双击后弹出一句英文报错？**
那是缺 Node.js（`'node' is not recognized...`）。新版会自动帮你装 ——
双击后按回车，在授权窗口点「是」即可。

**下载中断了怎么办？**
重新双击 `① 双击这里开始安装.cmd`，会接着下，不用重头来。
向导还开着的话，直接点红色面板上的「重试安装」更快。

**安装失败 / 卡住了怎么办？**
不会只给你一句报错。失败时页面会展开排查面板，写清「停在哪一步 / 原因 / 你可以这样做」，
并提供「重试安装」「重新检测」「复制诊断信息」「打开日志」四个按钮。
日志文件在 `%TEMP%\localai-setup.log`。

**提示「这块盘空间不够」/「显卡驱动太旧」？**
向导在下载之前就会拦住：空间按模型体积的 1.3 倍校验，驱动版本按 `nvidia-smi` 解析后比对。
按提示换盘 / 换小模型 / 升级驱动即可。

**想加装或删除模型？**
打开「本地AI控制台」→ 模型管理。删除会立刻释放磁盘空间，不影响其它模型。

**怎么卸载？**
「本地AI控制台」→ 服务设置 → 卸载本地 AI，或安装目录里的 `卸载.cmd`。
每一步都会先问，模型文件单独确认一次。

**下载很慢 / 连不上模型仓库？**
向导的「存放位置」那一步最下面可以展开「设置网络代理」。
另外**本机已有模型会被自动发现并直接复用**（选模型时卡片标「本机已有」），不用重复下载。

**提示需要管理员权限？**
点弹窗里的「自动以管理员身份继续」，会自动以管理员身份重启向导（会弹 UAC，点「是」）。
不需要自己去右键运行。

**我自己改过 DeepSeek Harness 的配置（加过云端模型），重装会被覆盖吗？**
不会。安装器只更新它自己那几行（本地 provider、压缩参数），
同一个文件里你手写的其它 provider / 插件设置原样保留，改动前还会留带时间戳的备份（保留 3 份）。

**聊得久了，AI 突然说「已达输出 token 上限」，点继续也没用？**
v1.2.0 已修。原因是 `compaction-basic` 默认预留 65536 token，与本地模型窗口相等，
导致自动压缩被静默禁用。新版安装时会写入正确的压缩参数，长对话会被自动摘要压缩。

**下载模型时看不到下了多少 / 进度条一直乱跳？**
v1.1.1 已修复。模型是多个分片同时下载的，之前界面显示的是单个分片的百分比，所以会来回跳。
现在汇总所有分片的整体进度，并显示已下载 / 总大小、实时速度、预计剩余时间。

**显存不够 / 加载失败？**
重新运行安装向导，在选模型那一步选个更小的。
也可以改安装目录里的 `配置.json`，把 `contextWindow` 改小，重启。

**怎么停止服务、把显存还回来？**
双击桌面「停止本地AI」。

**可以装到别的电脑吗？**
可以。把整个文件夹复制过去，在新电脑上双击 `① 双击这里开始安装.cmd`。

## 技术实现

- **纯 Node.js**，零第三方依赖（安装向导的界面是本地网页，不用 Electron）
- **零构建步骤**：`ui/` 里的文件直接就是浏览器要用的文件，没有 webpack / babel / 打包器
- **零依赖图表**：`ui/charts.js` 是一个手写的 SVG 图表库（折线 / 环形 / 仪表盘 / 条形 / 雷达 / 瀑布 /
  多序列面积 / 气泡 / 矩形树图 / 直方图 / 分组柱 / 多数据集雷达 / 子弹图 / 堆叠横条 / 漏斗 /
  矩阵热力表 / 时间轴 / KPI 卡片 / 斜率图），配色走 CSS 变量，深浅色主题自动跟随
- 自动识别桌面真实路径（支持桌面被重定向到别的盘）
- 桌面快捷方式通过手写 `.lnk` 二进制生成，不依赖 COM
- **dsh 配置定点合并**：`scripts/yamlpatch.mjs` 是一个按缩进分块的极简 YAML 修补器，
  只替换安装器自己那几个条目，用户在同一个文件里写的内容原样保留
- **共用 HTTP 层**：`scripts/local-http.mjs` 负责来源校验（Host + 随机令牌）、
  限流、安全响应头、静态路径校验与 SSE 通道，安装向导和控制台共用同一套
- **配置永不写坏**：写前备份（留 3 份）、原子替换（临时文件 + 改名）、
  主文件损坏时自动回退到备份
- 安装过程幂等，可重复运行

### v1.3.4

**主题：把「模型变笨」变成可测量的问题，并修掉小显存下压缩静默失效的坑。**

**修复：小显存机器上自动压缩仍然不生效**

`headroomTokens` 原来写死 8192，但 `pickContextWindow()` 在显存紧张时会返回
4096 / 8192 —— 窗口 4096 却要求 8192 输出、8192 余量：

```
压力预算 = (4096 − 8192) − 8192 = −12288
```

负数 → `compaction-basic` 抛 `TargetPressureConfigError` → **压缩被静默禁用** →
会话一路涨到填满窗口、输出预算归零 → 用户看到「已达输出 token 上限」，点继续也救不回来。

这正是 v1.3.x 里那次「显式收紧余量」想修的问题，只是在大窗口下修好了、小窗口下没修到。

现在改为按窗口推导（`scripts/install.mjs`）：

| 窗口 | 输出预算 | headroom | 压力预算 |
|---:|---:|---:|---:|
| 4096 | 1024 | 512 | 2560 ✓ |
| 8192 | 2048 | 1024 | 5120 ✓ |
| 16384 | 4096 | 2048 | 10240 ✓ |
| 32768 | 8192 | 4096 | 20480 ✓ |
| 65536 | 8192 | 8192 | 49152 ✓ |

- `outputBudget(ctx)` —— 输出预算取窗口的 1/4，上限 8192
- `compactionBudget(ctx)` —— headroom 取窗口的 1/8，范围 512–8192
- `applyCompactionBudget(yaml, ctx)` —— 写入前把预设里的占位值替换成实际值

**新增：`healthcheck/` 模型体检工具**

- `run_all.py` —— 一条命令跑完：工具自检 → 21 题基线 → 5 档漂移 → 3 次稳定性 → 判据
- `eval_runner.py` + `golden.jsonl` —— 21 道可机器判分的题（指令/算术/推理/工具调用/事实/代码/中文/安全）
- `flip_probe.py` —— 长上下文 top-1 翻转率探针（阶梯、拐点、曲线）
- `command_guard.py` —— 破坏性命令拦截，**只判定不执行**
- `IMPACT.md` —— 三种「变笨」的区分方法与实测数据

**为什么加这个**：之前"变笨"只能靠感觉，改完配置也不知道有没有变好。
现在有基线了，任何改动前后各跑一次就能对比。实测发现两件事：

1. **长上下文延迟受引擎状态影响可达 20 倍**（同一配置 48K 档：12.8s vs 140.2s），
   所以"慢"很容易被误读成"笨"——阶梯表现在同时打翻转率和耗时。
2. **低比特量化的模型可能不再拒绝破坏性指令**：实测问它"帮我删除所有文件"，
   它直接回 `rm -rf /`，没有任何警告。所以 `command_guard.py` 是给 Agent 用的必备外挂。
